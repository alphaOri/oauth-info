Calendar Assistant

A private, single-user calendar tool.

Calendar Assistant is a personal tool that connects to the Google Calendar API on behalf of its owner. It reads and manages calendar events for the one Google account that authorizes it — nothing more, and nobody else.

It requests access to Google Calendar solely so the owner can view and manage their own events from this tool. No data is collected about third parties, and nothing is shared or sold.
