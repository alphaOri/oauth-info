Privacy Policy

Calendar Assistant — last updated 2026-11-12

What this app is

Calendar Assistant ("the App") is a private, single-user tool operated by its owner. It connects to the Google Calendar API on behalf of the owner to read and manage the owner's calendar events.

Google user data we access

The App requests the OAuth scope https://www.googleapis.com/auth/calendar. It uses this access only to read, create, update, and delete calendar events belonging to the Google account that authorizes it.

How data is used and stored

Calendar data is processed locally on the owner's device to fulfil the owner's own requests. OAuth credentials (a refresh token) are stored locally by the App on that same device and are never transmitted anywhere except to Google's APIs.

Sharing and disclosure

No Google user data is sold, rented, or shared with any third party. The App does not use Google user data for advertising, and does not allow humans to read it except as required to operate the tool for the owner.

Retention and deletion

The owner can revoke the App's access at any time at myaccount.google.com/permissions, which immediately stops all data access. Locally stored credentials can be deleted by the owner at any time.

Contact

This is a private, single-user tool with no public user base, so no public contact channel is offered. The sole operator can be reached through the support email configured on the App's Google OAuth consent screen.

This policy applies only to the personal Calendar Assistant tool.
